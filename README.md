# zakariaejaafari.github.io

Personal site for [Zakariae Jaafari](https://zakariaejaafari.github.io/en/) — Full-Stack Software Engineer, Rabat.

Built from the CV and the three public GitHub repositories. Nothing on the site is invented.

**Live**

- English: [https://zakariaejaafari.github.io/en/](https://zakariaejaafari.github.io/en/)
- Français: [https://zakariaejaafari.github.io/fr/](https://zakariaejaafari.github.io/fr/)
- العربية: [https://zakariaejaafari.github.io/ar/](https://zakariaejaafari.github.io/ar/)

## What it contains

- Hero, about, experience, skills, featured projects, education, certifications, contact
- Dedicated pages for ChantiePro, the NYC taxi pipeline, and the face-detection app
- English and French CV PDFs in `public/cv/`
- Semantic HTML, JSON-LD, Open Graph, hreflang, sitemap, `robots.txt`

## Local development

Requires Node.js 22.12 or newer (CI uses Node 24).

```bash
npm install
npm run dev
```

```bash
npm run build
npm run preview
```
